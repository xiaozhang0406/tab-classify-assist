# tab-classify-assist (IceCola Tab Grouper)

自动整理浏览器标签页的 Chrome/Edge 扩展：**按域名自动分组 + 重复标签清理 + 排除规则 + 快捷键 + 会话快照防误关还原 + 标签冻结省内存 + Markdown 导出**。

> 这原本是作者「蚕啃树叶式」阅读习惯的解法——后台攒了几十个标签页想一个个啃完，又总怕误关丢失。于是做了这个扩展：分组看清、去重减负、快照兜底。

## 核心功能 (v2.2.0)

- **智能自动分组**：后台定时（空闲时）自动扫描并分组同域名标签，支持开关与间隔设置
- **🏷️ 常用站点友好别名映射**：内置 B站、知乎、GitHub、YouTube、V2EX、掘金、Google、百度等 30+ 常用站点的友好中文名称，并支持用户自定义扩展别名，彻底避免长串域名占满横向标签栏
- **❄️ 标签组一键休眠/冻结（省内存神器）**：利用 Chrome 原生 `chrome.tabs.discard` 能力，一键冻结指定组或所有后台标签，瞬间释放大量系统内存（保留标签位置与图标，点击无感唤醒）
- **📤 会话快照一键导出为 Markdown**：一键复制结构化 Markdown 知识库列表至剪贴板，方便将调研标签页随手归档至 Notion、Obsidian、微信读书或笔记软件
- **主域名智能聚合 (eTLD+1)**：支持将 `space.bilibili.com`、`live.bilibili.com` 等子站智能归类到统一主域名组中，支持自由开关
- **真正增量建组**：已存在的标签组可直接吸纳新打开的单个标签，无需等待凑满阈值
- **全局快捷键**：
  - `Alt + Shift + G`：立即智能分组
  - `Alt + Shift + D`：立即去重清理
- **安全防误关去重**：
  - **去重前自动快照**：每次执行去重关闭前，自动留存当前完整标签快照，不怕误关，随时一键还原
  - **关键参数保护**：平台追踪参数按域名针对性隔离，绝不全局清理 `mid`（B站用户ID）、`lang`（多语言文档）、`version`（API文档版本）、`from`（分页）等业务参数
  - **固定常驻标签保护**：用户固定（`pinned`）标签绝对不自动关闭
  - **智能识别 SPA 哈希路由**：区分单页应用路由（`#/route`、`#!/path`）与普通文章页面锚点（`#heading`）
  - **发声避让**：正在播放（`audible`）视频或直播的标签优先保留，静音重复标签可安全清理
- **当前窗口活动组管理**：Popup 面板可直接查看当前窗口的所有原生标签组，支持一键折叠/展开、单组休眠与单组快捷解散
- **排除规则（白名单）**：支持配置免分组域名（如 `localhost`, `*.internal.com`），边界匹配严密
- **单组恢复优化**：支持在历史快照中单独还原某一组，**直接恢复至当前正使用的窗口**，避免弹窗打扰
- **快照收藏防淘汰**：支持 ⭐ 收藏/锁定重要会话快照，防止被自动定时整理冲刷淘汰；自动过滤无变动的重复定时快照
- **多窗口合并安全保障**：默认关闭以保护多显示器/多虚拟桌面工作区；销毁空窗口前二次校验，杜绝竞态丢标签
- **图标角标状态感知**：扩展图标角标实时显示当前可清理的重复标签数
- **自适应深浅色主题**：自动跟随系统/浏览器主题（Dark / Light）无缝切换

## 加载（开发者模式）

### Chrome
1. 地址栏输入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本文件夹
4. 改代码后点扩展卡片上的刷新按钮

### Edge
1. 地址栏输入 `edge://extensions/`
2. 打开「开发人员模式」
3. 「加载解压缩的扩展」→ 选择本文件夹

## 快捷键配置

扩展默认快捷键为：
- `Alt + Shift + G`：一键分组
- `Alt + Shift + D`：去重标签

如需修改快捷键：
- Chrome：访问 `chrome://extensions/shortcuts`
- Edge：访问 `edge://extensions/shortcuts`

## 本地测试

项目包含基于 Node.js 原生 `node:test` 的自动化单元测试套件，覆盖核心域名提取、去重防误杀、分组增量逻辑、站点别名字典与 Markdown 导出：

```bash
npm test
```
