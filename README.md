# tab-classify-assist

自动整理浏览器标签页的 Chrome/Edge 扩展：**按域名自动分组 + 重复标签清理 + 会话快照防误关丢失**。

> 这原本是作者「蚕啃树叶式」阅读习惯的解法——后台攒了几十个标签页想一个个啃完，又总怕误关丢失。于是做了这个扩展：分组看清、去重减负、快照兜底。

## 功能

- **自动分组**：后台每 5 分钟（浏览器空闲时）扫描并分组同域名标签（可在 Popup 调整间隔）
- **一键分组**：点击扩展图标 → 立即分组
- **去重标签**：去掉 #锚点、?跟踪参数（utm_*、gclid、fbclid 等）后 URL 相同即判重复，自动关闭多余的，**保留最近用过的那一个**
- **会话快照**：每次分组前自动保存，误关后一键恢复，最多留 20 份
- **Chrome / Edge 通用**（都是 Chromium）

## 加载（开发者模式）

### Chrome
1. 地址栏输入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本文件夹
4. 改代码后点扩展卡片上的刷新按钮

### Edge
1. 地址栏输入 `edge://extensions/`
2. 打开「开发人员模式」
3. 「加载解压缩的扩展」→ 选择本文件夹

## 性能优化（1.1.0）

自动整理改为**增量分组**，做到无感：

- 只处理**未分组**的新标签，已有分组直接复用，不再每 5 分钟把全部标签重新分组一遍（旧版会反复挪动已分组的标签，导致标签栏重排卡顿）
- 标签栏没有变化时整轮**零操作跳过**，连快照都不写
- 正在播放（视频/直播）的标签本轮不动，静音后再归组；去重也不会关闭正在播放的标签
- 分组操作按组**错峰执行**，把标签栏重排分散到多个帧
- 只管理自己创建的组，用户手动建的组不会被拆散或改名

## 无感优化（1.2.0）

- **互斥串行**：同一时刻只允许一个整理流程执行。闹钟、一键分组、安装事件并发触发时会重复建组、重复关标签、互相覆盖元数据——现在忙时新请求只记一次「待重跑」，当前流程结束后自动补跑
- **分批执行**：建组每次最多挪动 6 个标签、关标签每次最多 4 个，批次间隔 80ms，把标签栏重排与关闭分散到多个帧，不再一次性大重排
- **空闲时才自动执行**：自动分组前先查 `chrome.idle`（30 秒无操作），你在用浏览器时整轮跳过，离开后再悄悄整理；手动点按钮不受限
- **跨窗口分组修复**：按（窗口, 域名）分桶，同域名分散在多个窗口时不再建组失败

## 调试

- Service Worker 日志：扩展卡片 →「Service Worker」链接 → Console
- 快捷调试：在 SW Console 执行 `chrome.tabs.query({})` 查看当前标签

## 技术栈

- Manifest V3
- `chrome.tabs.group()` / `chrome.tabGroups.update()` 创建原生标签组
- `chrome.alarms` 定时触发
- `chrome.storage.local` 持久化会话
