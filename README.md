# tab-classify-assist (IceCola Tab Grouper)

自动整理浏览器标签页的 Chrome/Edge 扩展：**按域名自动分组 + 重复标签清理 + 排除规则 + 快捷键 + 会话快照防误关还原**。

> 这原本是作者「蚕啃树叶式」阅读习惯的解法——后台攒了几十个标签页想一个个啃完，又总怕误关丢失。于是做了这个扩展：分组看清、去重减负、快照兜底。

## 核心功能 (v2.0.0)

- **智能自动分组**：后台定时（空闲时）自动扫描并分组同域名标签，支持开关与间隔设置
- **全局快捷键**：
  - `Alt + Shift + G`：立即智能分组
  - `Alt + Shift + D`：立即去重清理
- **安全去重**：
  - 智能识别并保护 SPA 单页应用哈希路由（`#/route`、`#!/path`），绝不误删单页应用工作页面
  - 深度剥离主流平台追踪参数（UTM、B站 `spm_id_from`、微信 `chksm`、小红书、知乎、微博等）
  - 优先保留当前激活（`active`）与固定常驻（`pinned`）标签页
- **排除规则（白名单）**：支持配置免分组域名（如 `localhost`, `*.internal.com`）
- **自动折叠分组**：建组完成后可自动折叠（`autoCollapse`），极大节省横向标签栏空间
- **一键解散分组**：需要恢复平铺标签栏时，一键解散所有原生分组
- **多窗口合并**：整理前可自动将所有普通窗口标签归入主窗口，清空后自动销毁空窗口
- **完整会话快照与分组还原**：
  - 真实捕获最新建组与去重结果，支持展开预览每个快照的具体网页标题
  - 恢复会话时**完整重建原生标签分组**（还原标题与配色）
  - 支持**单独恢复某一特定分组**，无需全部打开
- **自适应深浅色主题**：自动跟随系统/浏览器主题（Dark / Light）无缝切换

## 加载（开发者模式）

### Chrome
1. 地址栏输入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选择本文件夹
4. 改代码后点扩展卡片上的刷新按钮

### Edge
1. 地址栏输入 `edge://extensions/`
2. 打开「开发人员模式」
3. 「加载解压缩的扩展」→ 选择本文件夹

## 快捷键配置

扩展默认快捷键为：
- `Alt + Shift + G`：一键分组
- `Alt + Shift + D`：去重标签

如需修改快捷键：
- Chrome：访问 `chrome://extensions/shortcuts`
- Edge：访问 `edge://extensions/shortcuts`
